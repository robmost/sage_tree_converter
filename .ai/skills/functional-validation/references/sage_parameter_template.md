# SAGE Parameter File Template

Two template blocks are provided below - one for each output format. Copy the
appropriate block to `assets/test_sage_params.par` and fill in the placeholders
marked with `<...>`. All other values are conservative defaults suitable for a
Stage 2 functional validation dry run.

**Important:** Do **not** include a `TreeExtension` key in either template - SAGE sets
the file extension internally (`lhalo_hdf5` -> `.hdf5`; `lhalo_binary` -> empty) and
will abort with "Tag 'TreeExtension' not allowed" if the parameter appears.

## Template A - `lhalo_hdf5` output

**Path note:** SAGE resolves the HDF5 tree file as `<SimulationDir>/<TreeName>.<FirstFile>.hdf5`.
For a single-file output named `test_mini_millenium.0.hdf5` in `assets/`, set
`SimulationDir = assets/` and `TreeName = test_mini_millenium`.

**Path note:** SAGE resolves the binary tree file as `<SimulationDir>/<TreeName>.<FirstFile>` (no
extension). For a single-file output named `test_mini_millenium.0` in `assets/`, set
`SimulationDir = assets/` and `TreeName = test_mini_millenium`.

**`PartMass` is mandatory.** Binary files contain no particle mass field; SAGE reads it
exclusively from this parameter. Set it to the same value used by the driver (units: 10^10 Msun/h).

## Required placeholders

| Placeholder | Where to find it |
| ----------- | ---------------- |
| `ABSOLUTE_PATH_TO_ASSETS` | Absolute path to `assets/` in the project root |
| `TREE_BASE_NAME` | Base name of the test output HDF5 without the `.0.hdf5` suffix (e.g. `test_mini_millenium`) |
| `LOWEST_SNAP_NUMBER` | `max(SnapNum)` across all trees in the test output file (e.g. `63` for a 64-snapshot simulation) |
| `OMEGA_MATTER` | Simulation cosmological parameter (e.g. `0.307`) |
| `OMEGA_LAMBDA` | Simulation cosmological parameter (e.g. `0.693`) |
| `HUBBLE_H` | Dimensionless Hubble parameter (e.g. `0.678`) |
| `PARTICLE_MASS` | `Header.attrs["ParticleMass"]` from the test output HDF5 (units: 10^10 Msun/h) |
| `BOX_SIZE_MPC_OVER_H` | Simulation box size in Mpc/h |
| `ABSOLUTE_PATH_TO_SNAP_LIST` | Absolute path to the snapshot scale-factor list (e.g. `assets/<dataset>_snaplist.txt`). **Mandatory - SAGE rejects an empty value.** Extract from the input data in Step 2 of the skill if no pre-existing list is available. |

## Multi-file naming convention

SAGE constructs tree file paths as `<SimulationDir>/<TreeName>.<FileIndex>[.hdf5]`:

| Format | Path pattern | Example |
| --- | --- | --- |
| `lhalo_hdf5` | `<TreeName>.<N>.hdf5` | `test_mini_millenium.0.hdf5` |
| `lhalo_binary` | `<TreeName>.<N>` | `test_mini_millenium.0` |

Set `SimulationDir` to the directory containing the file and `TreeName` to the base
name **without** the `.<N>[.hdf5]` suffix.

## Notes

- Create the output directory before running SAGE: `mkdir -p assets/sage_test_output`
- `OutputFormat = sage_hdf5` writes SAGE galaxy catalogues as HDF5; this avoids
  binary output portability issues during a dry run.
- The `-> <LOWEST_SNAP_NUMBER>` line under `NumOutputs 1` specifies which snapshot
  to output; it must match `LastSnapShotNr`.
- If SAGE complains about a missing parameter, add it with its default value. Do not
  modify the input HDF5 to work around a parameter error.
